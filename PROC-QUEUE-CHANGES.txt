CHANGES TO MAKE: Purchase queue (accept = supplier pop-up, no supplier field, accepted items highlighted)
========================================================================================

What changes for the user
  - The Stock top-up form and the review table (Awaiting decision) have NO supplier field any more.
  - Pressing Accept (on a row, or on the selected rows) opens a pop-up: pick the supplier, or add a new one from
    the same pop-up. Choosing the supplier is what accepts the requirement. Accept without a supplier is refused.
  - A stock top-up joins the queue as "Awaiting decision" (it is no longer auto-accepted).
  - In Accepted (and in All), items accepted but not yet on a purchase order are highlighted in green, with a banner,
    a "Ready to order" label under the status, and a green Accepted filter button while any are waiting.
  - The Supplier column is hidden while reviewing and shown for Accepted / Ordered / Denied / All.

How to apply
  Three files change: Procurement.gs, ProcQueueBoard.html, DeptStyles.html.
  For each numbered edit: find the FIND text in the file (the lines marked ' ' are only there to make the place
  unique and are repeated unchanged in the REPLACE text), and replace the whole FIND block with the REPLACE block.
  Lines starting with '-' in a diff do not appear here: FIND is exactly the old text, REPLACE is exactly the new text.
  No other file changes. Redeploy a new version afterwards.
