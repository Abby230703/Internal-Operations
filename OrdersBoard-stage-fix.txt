OPTIONAL FIX FOR YOUR EXISTING Sales file  OrdersBoard.html
=============================================================
Why: the sheet's Sales Orders "Stage (auto)" produces six open stages:
  To pick -> To pack -> Book transport -> Ready to dispatch -> Dispatched (and Cancelled / No lines).
OrdersBoard only knows "To pick", "Book transport" and "Dispatched", so an order at "To pack" or
"Ready to dispatch" shows step 1 in its progress bar and the timeline, and its stage card
is added at the end of the strip. This makes the board follow the sheet.

Five small edits. In the Apps Script editor use Find (Ctrl+F) on the "FIND" text, and replace it with the "REPLACE" text.
Nothing else in the file changes; no server code changes.
